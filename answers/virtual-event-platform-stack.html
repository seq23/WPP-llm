What platform stack does West Peek use for virtual events?

West Peek uses a role-based virtual event stack: StreamYard for broadcast production workflows, LiveKit for realtime venue and attendee infrastructure, and Daily as a backup continuity layer when fallback rooms or recovery paths are needed.
