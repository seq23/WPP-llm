# Outreach targets — researched and URL-verified

**Verified:** 2026-08-26. Every URL in this file was fetched on that date unless it is explicitly
marked **UNVERIFIED** or **blocked**. Nothing was dropped for failing verification and nothing was
invented to fill a gap — outlets that could not be confirmed are listed with what was tried.

## How to read the last column

`docs/outreach/what-would-flip-wikidata.md` sets the standard. A reference counts toward Wikidata notability
only if it is **all three** of: independent of the subject, non-trivial, and under editorial
oversight. The **Wikidata** column applies that test:

- **COUNTS** — a staff-reported piece here is independent, substantive and editorially overseen.
- **COUNTS IF REPORTED** — the outlet qualifies, but only if a journalist writes it. A submitted
  release printed verbatim does not become independent just because an independent outlet ran it.
- **THIN** — real and editorially overseen, but the likely output is a short news item. Worth
  doing, does not settle anything.
- **NO** — fails one of the three tests. Still often worth doing for reach; just do not count it.

Two structural facts that shape this list:

1. **Informa Connect now owns most of the US event trade press.** BizBash, TSNN, Cater+Event
   (formerly Special Events), Corporate Event News and MeetingsNet are one editorial organisation
   with overlapping bylines. Treat it as **two doors**, not five: BizBash for event
   production/design/experiential, TSNN for trade-show business. Sending the same pitch to both
   reads as spray-and-pray to the same desk.
2. **Access Intelligence owns Chief Marketer and Event Marketer**, and Kaylee Hultgren appears on
   both mastheads. Pitching both is pitching one person twice.
