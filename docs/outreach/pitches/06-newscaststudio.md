**Subject:** Query — case study on redundancy design for corporate executive broadcasts

Hi Dak,

Query before submitting anything, per your contribute page.

Corporate executive broadcasts have quietly adopted broadcast-control-room thinking without the
broadcast budget, and the interesting engineering problem is redundancy. When a CEO is live to
the whole company, "we'll restart the call" is not a recovery plan.

We build these to a three-layer architecture: a StreamYard-based broadcast workflow as the
primary path, LiveKit-based realtime rooms when the format needs genuine attendee interaction
rather than an audience, and pre-provisioned Daily rooms as a backup venue the production team
can move the whole event into. Plus the human layer that actually decides — rehearsed handoffs,
backstage moderation, and a named person with authority to call the switch.

West Peek Productions has produced 400+ virtual and hybrid experiences since 2020, including
Fortune 500 internal leadership events. I can write this as a case study with production stills,
or answer questions for a features piece — whichever suits.
