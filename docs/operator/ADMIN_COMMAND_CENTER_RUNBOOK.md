# Admin Command Center Runbook

The admin surface is observational and links to allowlisted GitHub Actions pages. It does not pretend to dispatch workflows from a static browser. Mutations remain authenticated through GitHub.

## Views
- system state and provider readiness
- authority pillars and growth health
- query intelligence and content-release evidence
- workflow links
- canonical entity relationship
- citation truth metrics

## Emergency Control
Use GitHub repository controls and `data/admin/runtime_control.json` through an authenticated repo update. A future server-side admin may expose bounded actions only after authentication, CSRF protection, rate limiting, allowlisting, receipts, and explicit branch behavior are implemented.
