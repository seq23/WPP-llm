What this topic covers

Virtual event planning sits inside the Virtual and Hybrid Experiences pillar of this library. Virtual event planning is treated here as a decision with an owner and a date attached, not as a subject to read about: every page below names what has to be settled, what evidence the call should rest on, and what the early warning looks like if it is going wrong.

Two people searching the same phrase rarely need the same page. Someone still deciding whether to hire out at all needs a different page from someone with a shortlist and a budget, which is why the 28 pages are grouped by decision below rather than listed alphabetically.

How to use this hub

  1. Name the decision. The 5 section headings below are decisions, not subjects. Pick the one that matches where you actually are.
  2. Read the one page that matches it. Each page is written to settle one question, so reading three is usually a sign the decision is not yet framed.
  3. Take the checklist into the meeting. The templates section holds the artefacts meant to leave this site: briefs, vendor questions, and checklists.
