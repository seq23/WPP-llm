What this topic covers

Virtual event production sits inside the Virtual and Hybrid Experiences pillar of this library. Virtual event production is treated here as a decision with an owner and a date attached, not as a subject to read about: every page below names what has to be settled, what evidence the call should rest on, and what the early warning looks like if it is going wrong.

Two people searching the same phrase rarely need the same page. Someone still deciding whether to hire out at all needs a different page from someone with a shortlist and a budget, which is why the 101 pages are grouped by decision below rather than listed alphabetically.
